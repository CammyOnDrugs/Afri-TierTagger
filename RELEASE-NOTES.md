# Afri-TiersTagger 2.8.6

Minecraft 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 and 26.3. Install only the matching JAR.

- Four icon styles across 18 modes, with all 72 icons rebuilt and centred at 256px.
- Queue menu and linked-account status; RocketMace and HoleFight kit identification.
- Peak/main/subtier switches, colour controls and animated menus.
- Separate Name Tags and Tab List switches; no hologram tagging.
- Own tier in F5 enabled by default. Ranking-number switch also hides podium trophies.
- Minecraft style locks Liquid Glass off. Search Players/profile screens use solid backgrounds.
- Settings reordered, Search Players last; modern/legacy menu navigation and official download links.
- Modrinth/GitHub updater verifies checksums, waits for Minecraft to exit, and retains a backup.
- Version 2.8.6 is not obfuscated.

All six local Gradle builds passed; this publication also requires all six GitHub Actions matrix builds to pass. Changed 2.8.6 code has not been launched in a client during this handover. Earlier 2.8.5 runtime checks do not establish runtime validation for this release. Live authenticated queue/F5 checks and an actual client auto-update remain untested.

This is a client-mod release. It contains no bot credentials, staff handbook or private server configuration.
